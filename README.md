# Finance

Трекер личных финансов на React: добавление доходов и расходов, фильтрация, дашборд и график расходов.

**Демо:** https://xaidx.github.io/Finance/

![Finance](screenshots/screenshot.png)

## Возможности

- Добавление транзакций
- Список транзакций с фильтрами
- Дашборд с итогами
- График расходов

## Стек

React 19, Vite, Tailwind CSS, Recharts

## Запуск локально

    npm install
    npm run dev
